# E-Commerce Fulfillment

Complete e-commerce order fulfillment workflow spanning five lanes: customer, sales, warehouse, shipping, and finance. Covers the entire order lifecycle including payment processing, fraud detection, inventory allocation, pick-and-pack, carrier selection, delivery tracking, return handling, and loyalty rewards. Rules files encode fraud detection heuristics, warehouse selection logic, carrier routing by weight and destination, return eligibility windows, and loyalty points calculation.
